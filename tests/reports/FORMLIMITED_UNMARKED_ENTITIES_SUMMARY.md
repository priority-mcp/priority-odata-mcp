## ❌ 3. יישויות לא נגישות (4,227 יישויות)

יישויות שלא נגישות דרך REST API. רוב היישויות (99.2%) לא נגישות, מה שמצביע על כך שרוב המסכים ב-Priority לא מוגדרים לגישה דרך REST API.

### פילוח לפי סוג שגיאה:

יישויות שמחזירות שגיאת 400. זה יכול להצביע על:
- יישויות שדורשות פרמטרים נוספים
- יישויות שלא תומכות ב-REST API
- יישויות שדורשות הרשאות מיוחדות

**דוגמאות ליישויות עם שגיאת 400:**
- ABILITIES, ABILITYVALUECODES, ABSENTCHART, ABSENTCODES
- ACCBAL, ACCBALLOG, ACCCONST, ACCDATES
- ACCOUNTBANKCHANGES2, ACCOUNTBANKSUP_LOG
- ADCAIVLOG, ADCBPMADC, ADCCCLOG
- ועוד 1,680 יישויות נוספות

#### שגיאות 404 Not Found (2,534 יישויות - 59.9%)

יישויות שמחזירות שגיאת 404. זה יכול להצביע על:
- יישויות שלא קיימות במערכת
- יישויות שלא זמינות דרך REST API
- יישויות שדורשות הגדרה מיוחדת

**דוגמאות ליישויות עם שגיאת 404:**
- ABILITYVALUES, ACCCUST, ACCOUNTBANK
- ACCOUNTSTEXT, ACTALT, ACTBRANCH
- ACTTEXT, ACTVAR, ADDRESSES
- ועוד 2,524 יישויות נוספות

### המלצות:
- **לא לסמן יישויות אלה ב-RESTFLAG=Y** עד שיתברר מדוע הן לא נגישות
- יישויות עם שגיאת 400 עשויות לדרוש הגדרה מיוחדת או פרמטרים נוספים
- יישויות עם שגיאת 404 כנראה לא קיימות או לא זמינות דרך REST API
